## フォーカス
このプログラムでは下記をポイントにプログラムを行う。わからないことがあれば検索、また質問すること

1. randomモジュールのインポート
2. 「リスト」の扱い

### リストの書き方
下記のように **[ ]**の中で書きます。リストの番号は０から始まるので注意。

```python

dinner = ["カレー","バンバーグ","生姜焼き","お好み焼き","パスタ"]

```


### モジュールのインポート
pythonでは、モジュールと呼ばれる便利な機能をimportで呼び出すだけでプログラムの中で使えます。ここではrandomモジュールを呼び出します。

```python

import random

```

## 実装

randomモジュールを呼び出し、リストの中からランダムに選ぶようにします。
できたら実行してみてください。

```python

import random
dinner = ["カレー","バンバーグ","生姜焼き","お好み焼き","パスタ"]
print(random.choice(dinner))

```
